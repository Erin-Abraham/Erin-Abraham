# Hi, I'm Erin Abraham 👋

Striving for personal growth — currently exploring the intersection of **computer vision**, **generative AI**, and applied research.

## 🔭 What I'm working on

- **[TraceVision](https://github.com/NexusCore-Labs/TraceVision)** — an AI-powered forensic investigation portal that lets law enforcement and security analysts search CCTV footage for specific visual events using plain-language queries.
- **[dr-pipeline](https://github.com/Erin-Abraham/dr-pipeline)** — a Diminished Reality pipeline that removes target objects from digital scenes, comparing classical OpenCV inpainting against a locally-hosted Stable Diffusion approach (running within a 6GB VRAM constraint).
- **[2DShooter](https://github.com/Erin-Abraham/2DShooter)** — a 2D shooter game built in C#.
